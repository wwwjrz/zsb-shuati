# 专升本真题刷题 · 使用说明

政治为主、英语为辅的历年真题刷题平台（手机优先网页应用，无需安装、无账号、记录只存在你手机本地）。

## 怎么用

**电脑上启动一次：**

双击 `serve.sh`（或终端里执行 `./serve.sh`）

屏幕会显示两个地址：
- 电脑自己刷：http://localhost:8000
- **手机刷（重点）**：确保手机和电脑连同一个 WiFi，用手机浏览器打开屏幕上显示的 `http://192.168.x.x:8000`

**手机上像 App 一样用：**
- iPhone：Safari 打开 → 分享 →「添加到主屏幕」
- 安卓：Chrome 打开 → 菜单 →「添加到主屏幕」

之后从主屏幕图标进入就是全屏 App 体验，且支持离线使用（Service Worker 已缓存题库）。

## 功能一览

| 功能 | 说明 |
|------|------|
| 历年真题 | 按科目→年份进入；练习模式（每题即时判分+解析）、考试模式（150分钟计时、答题卡、交卷出分） |
| 政治主观题 | 辨析/简答/论述两种练法：真题里点开参考答案自评；或用首页「政治背诵卡」按年份/题型专项背 |
| 随机组卷 | 自选科目、年份范围、题量；「智能抽题」优先抽你没做过和做错的题；交卷出掌握度报告（分科目/分题型正确率+薄弱点提示） |
| 错题本 | 做错自动收录，答对自动移出；可分组重练或全部混合重练 |
| 统计 | 每年刷题进度、正确率、最近练习记录 |
| 政治加练 | 老师发的选择题498（挖空自测版），点开看答案自评会/不会 |

## 数据说明

- `data/politics.json` / `data/english.json`：12 年真题题库（由 PDF 转录校验生成）
- `data/extra.json`：政治 498 加练题
- 答题记录存在手机浏览器 localStorage，清浏览器数据会丢失记录
- 想重置全部记录：首页地址栏后加 `#` 不行——在浏览器控制台执行 `localStorage.removeItem('scft.v1')` 或清除网站数据
